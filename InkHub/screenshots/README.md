# InkHub screenshots

Six screenshots for the s-INK for Trello listing on InkHub, in the order they should
appear. InkHub publishes no size or format rules, so they are full-screen
captures taken on the Manta (1920 × 2560 in portrait), saved as PNG and left
uncropped.

## Before taking them

- Use a demo Trello board (e.g. "Garden shed" or "Book club"), not real work
  boards: no client names, e-mail addresses or personal photos on screen.
- Give the demo board 3 or 4 lists (`To do`, `Doing`, `Done`), a few labels
  with names (`TODO`, `WIP`, `Urgent`), two members and cards with
  checklists, a description and a comment.
- Language: English, so the listing matches its description.
- Turn diagnostic mode off if it is on, so no Inspect button or Diagnostics
  category shows.
